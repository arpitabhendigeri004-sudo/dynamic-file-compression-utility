## 🚀 Overview

Dynamic File Compression Utility is a modern file compression and decompression application built using Python, Huffman Coding, and Streamlit.

The project demonstrates how lossless compression techniques can reduce file size while preserving original content. It includes a professional dashboard, analytics, reports, compression statistics, and file management features.

---

## ✨ Features

* 📥 File Compression
* 📤 File Decompression
* 🌳 Huffman Coding Algorithm
* ⚡ Fast Processing
* 📊 Analytics Dashboard
* 📄 Compression Reports
* 📈 Compression Trend Visualization
* 🎨 Modern Streamlit Interface
* 📁 File Management
* 📉 Compression Ratio Analysis

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/dynamic-file-compression-utility.git
cd dynamic-file-compression-utility
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

## ▶️ Running the Application

Launch the dashboard:

```bash
streamlit run dashboard.py
```

Open:

```text
http://localhost:8501
```
